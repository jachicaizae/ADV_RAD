Recurso interactivo elaborado para la asignatura Análisis de Datos y Visualización (CICO2000). La API usada en la simulación es ficticia y sus datos son de ejemplo.

Glosario rápido

API
Interfaz que permite que dos sistemas de software se comuniquen e intercambien datos o funcionalidades bajo reglas definidas.
API REST
API que usa los métodos estándar de HTTP para operar sobre recursos; suele responder en JSON.
Recurso
Elemento que ofrece la API: dispositivos, usuarios, mediciones, etc.
Endpoint
URL específica del recurso al que se envía la solicitud.
Métodos HTTP
GET obtiene información; POST crea; PUT actualiza; DELETE elimina.
Parámetros
Valores que filtran o acotan la consulta, por ejemplo ciudad=Loja o limite=5.
API key
Clave única que identifica a quien consume la API; permite identificación, control de uso y seguridad.
Código de estado
Número que indica el resultado: 200 éxito, 201 creado, 400 solicitud incorrecta, 401 no autorizado, 404 no encontrado.
JSON
Formato de texto con pares clave–valor y listas; es la respuesta más común de las APIs REST.
