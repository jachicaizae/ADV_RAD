Explorador PCA

Análisis de Componentes Principales explicado con métricas de una red ficticia
    Glosario
    Dimensión
    Número de variables (columnas) de un dataset. Ocho métricas por evento = ocho dimensiones.
    Varianza
    Cuánto se dispersan los valores. En PCA se usa como medida de la «información» que contiene una dirección.
    Estandarizar
    Restar la media y dividir para la desviación estándar de cada variable (puntaje z). Así todas quedan en la misma escala.
    Componente principal (CP)
    Nueva variable formada como combinación lineal de las originales. PC1 captura la mayor varianza; PC2, la mayor varianza restante, perpendicular a PC1.
    Varianza explicada
    Porcentaje de la varianza total que conserva cada componente. La acumulada indica cuánta información se conserva con las primeras k componentes.
    Carga (loading)
    Peso de una variable original en una componente. Con datos estandarizados se interpreta como su correlación con la componente (entre −1 y 1).
    Proyección
    Representación de cada observación con las nuevas coordenadas (PC1, PC2…). Permite ver el dataset en 2D.
